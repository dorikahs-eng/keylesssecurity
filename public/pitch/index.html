03 — Built for the portfolio, not the door

What administrators
actually control

FEATURE — ENTRY CODES

Personalized entry codes

  • One code per person — never shared, never duplicated
  • Issued the moment a lease starts
  • Revoked the moment it ends — no rekey required
FEATURE — SCHEDULED ACCESS

Time-specific entry windows

  • Codes that only work within a set window
  • Built for contractors, inspectors, and one-time visits
  • Access expires on its own — nothing to remember to disable
FEATURE — ADMINISTRATION

Centralized administrator control

  • Every property, every door, in one place
  • Permission levels by role — site staff see only their site
  • Changes apply instantly, with no site visit needed
FEATURE — ALERTS

Unauthorized attempt alerts

  • Failed entries are flagged the moment they happen
  • Repeated attempts surface as a pattern, not a guess
  • A standing record for any dispute that follows
